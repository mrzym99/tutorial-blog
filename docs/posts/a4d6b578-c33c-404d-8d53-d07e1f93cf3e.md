## 二、选哪种安装方式？

| 方式 | 适用 | 特点 |
|---|---|---|
| **nvm** | 推荐（开发必装） | 随时切换多个 Node 版本，升级/回退零成本 |
| 官方安装包 | 快速上手 | 一条路装完，但换版本麻烦，易残留 |
| 包管理器（brew / winget / apt） | 已有生态 | 简单，但版本滞后，混装易出问题 |

> 作为前端开发者，强烈建议用 **nvm** 一类的版本管理工具，一个项目对应一个 Node 版本非常常见。

## 三、Windows 安装

### 方案 A：nvm-windows（推荐）

1. 到 [nvm中文网](https://www.nvmnode.com/zh/guide/download.html) 的下载，下好后安装即可。
2. 重新打开终端，安装并切换 Node：

```bash
nvm install 24        # 安装 Node 24 LTS
nvm use 24           # 切换使用
nvm ls               # 查看已安装版本
nvm alias default 24 # 设为默认版本
```

### 方案 B：winget（一行搞定）

```bash
winget install OpenJS.NodeJS.LTS
```

### 方案 C：官方安装包

去 [nodejs.org](https://nodejs.org) 下载 Windows LTS 版 `.msi`，全程默认下一步即可（会自动配置 PATH）。

## 四、macOS 安装

### 方案 A：nvm（推荐）

```bash
# 安装 nvm（版本号以仓库最新 tag 为准）
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.3/install.sh | bash

# 重开终端后
nvm install 24
nvm use 24
nvm alias default 24
```

### 方案 B：Homebrew

```bash
brew install node@24

# 如需全局可用，追加 PATH：
echo 'export PATH="/opt/homebrew/opt/node@24/bin:$PATH"' >> ~/.zshrc
```

### 方案 C：fnm（更快，Rust 编写）

```bash
brew install fnm
echo 'eval "$(fnm env --use-on-cd)"' >> ~/.zshrc
fnm install 24
fnm default 24
```

### 方案 D：n（更轻量的版本管理）

[n](https://github.com/tj/n) 是另一个 Node 版本管理器，比 nvm 更简洁，一条命令装/切：

```bash
# 安装（任选其一）
brew install n
# 或
npm install -g n

# 使用
n 24            # 安装并切换到 Node 24
n latest        # 安装最新版
n lts           # 安装最新 LTS
n list          # 查看已安装版本
n rm 20.0.0     # 删除指定版本
```

> 注意：`n` 默认把版本装到系统目录（`/usr/local/n`），可能需要 `sudo`；nvm 则完全装在用户目录、无需权限。两者选其一即可，不要混用。

## 五、常见问题排查

| 现象 | 原因与解决 |
|---|---|
| `node` 不是内部或外部命令 | PATH 未生效：重开终端 / 注销重登，或手动把 nvm 目录加入 PATH |
| `nvm install` 下载卡住 | 网络问题，设置 nvm 镜像：`NVM_NODEJS_ORG_MIRROR=https://npmmirror.com/mirrors/node/` |
| `npm install` 权限报错 | 不要用 `sudo`，改用 nvm 安装 Node（装在用户目录）即可 |
| 项目要求老版本（如 16/18） | `nvm install 18 && nvm use 18`，秒切 |
| 装了新版后全局工具失效 | 全局工具按当前版本重装：`npm i -g <工具名>` |
