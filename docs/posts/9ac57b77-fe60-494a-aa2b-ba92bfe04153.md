## 插件功能说明

这些 npm 包都是 **pi 编码 agent 的扩展插件**，用于为 agent 增加各类能力，按功能整理如下：


| 插件                                     | 类别     | 具体功能                                                                           |
| -------------------------------------- | ------ | ------------------------------------------------------------------------------ |
| npm:@juicesharp/rpiv-todo              | 任务管理   | 让 agent 在执行多步骤任务时维护结构化待办清单，实时创建 / 更新 / 勾选任务，避免遗漏步骤、便于跟踪进度。                     |
| npm:@juicesharp/rpiv-ask-user-question | 用户交互   | agent 遇到需要决策的地方会暂停并向你提问（通常带候选项），拿到答复后再继续执行，避免自作主张。                             |
| npm:@narumitw/pi-plan-mode             | 计划模式   | 类似 Claude Code 的 Plan Mode：先产出执行计划供你审阅和修改，批准之后才真正动手改代码。                        |
| npm:billion-context                    | 超长上下文  | 扩展 pi 的上下文管理能力，支持塞入 / 检索远超默认窗口的大体量资料（具体机制以其 README 为准）。                        |
| npm:pi-cc-extensions                   | 功能合集   | "CC" 即 Claude Code：把 Claude Code 中的常用机制（计划、任务、交互等）移植成 pi 可用的一揽子扩展。             |
| npm:pi-memory                          | 持久记忆   | 让 pi 跨会话记住项目背景、编码偏好与约定（读写记忆文件），新会话自动加载，不用每次重复交代。                               |
| npm:pi-subagents                       | 多代理协作  | 允许主 agent 派生子 agent，并行 / 隔离地完成子任务（检索、重构、跑测试等），再把结果汇总回来。                        |
| npm:@gotgenes/pi-permission-system     | 安全权限   | 对 agent 可执行的工具 / 命令做细粒度管控：白名单直接放行，敏感操作需人工确认，防止误删误改。                            |
| npm:pi-mcp-adapter                     | 外部工具接入 | 通过 MCP（Model Context Protocol）把外部 MCP 服务器的工具和数据接入 pi，让 agent 能调用数据库、浏览器、API 等。 |
