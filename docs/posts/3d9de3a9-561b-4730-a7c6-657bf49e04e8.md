# Magpie 介绍与安装教程

[**Magpie**](https://usemagpie.ai/zh/) 是知名开源开发者 **yetone**(代表作 OpenAI Translator、Bob 翻译插件等)维护的 GitHub 开源项目:[github.com/yetone/magpie](https://github.com/yetone/magpie)。项目免费开源,可自由使用、审计与二次开发。

## 一、项目简介

- **免费开源**:源码托管在 GitHub,无广告、无订阅。
- **开箱即用**:官方提供预编译安装包,下载即可使用。
- **跨平台**:支持 Windows / macOS / Linux(以 Releases 页面实际提供的版本为准)。
- **持续迭代**:作者更新勤快,建议给仓库点个 Star 以获取最新动态。

## 二、安装教程

打开官网下载自己电脑对应版本就好

## 三、首次使用

启动 Magpie,熟悉主界面。
