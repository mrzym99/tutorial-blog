# Magpie 介绍与安装教程

[**Magpie**](https://usemagpie.ai/zh/) 是知名开源开发者 **yetone**(代表作 OpenAI Translator、Bob 翻译插件等)维护的 GitHub 开源项目:[github.com/yetone/magpie](https://github.com/yetone/magpie)。项目免费开源,可自由使用、审计与二次开发。

## 一、项目简介

- **免费开源**:源码托管在 GitHub,无广告、无订阅。
- **开箱即用**:官方提供预编译安装包,下载即可使用。
- **跨平台**:支持 Windows / macOS / Linux(以 Releases 页面实际提供的版本为准)。
- **持续迭代**:作者更新勤快,建议给仓库点个 Star 以获取最新动态。

## 二、安装教程

1. 打开官网下载自己电脑对应版本就好

## 三、首次使用

1. 启动 Magpie,熟悉主界面。

## 四、常见问题

:::details

:::detailsSummary

macOS 提示"已损坏,无法打开"或"无法验证开发者"?

:::

:::detailsContent

到「系统设置 → 隐私与安全性」点击"仍要打开";若提示"已损坏",在终端执行:`sudo xattr -d com.apple.quarantine /Applications/Magpie.app`

:::

:::

:::details

:::detailsSummary

GitHub 下载太慢?

:::

:::detailsContent

可在下载链接前加镜像加速前缀(如 `https://mirror.ghproxy.com/`),或通过代理访问 Releases 页面。

:::

:::

:::details

:::detailsSummary

Releases 里没有我系统的安装包?

:::

:::detailsContent

部分平台可能需要从源码自行构建,请以仓库 README 的构建说明为准。

:::

:::
