# CC Switch 安装指南

## 简介

**CC Switch** 是一款跨平台桌面应用(Tauri 2 构建),用于统一管理 **Claude Code、Claude Desktop、Codex、Gemini CLI、Grok Build、OpenCode、OpenClaw、Hermes** 八个 AI 编程工具的 API Provider 配置。内置 50+ 供应商预设,点一下即可切换 API 地址、Key 与模型,支持统一管理 MCP、Prompts、Skills,并带系统托盘快捷切换、用量统计、云同步等功能。

- **GitHub**:<https://github.com/farion1231/cc-switch>
- **官方网站**:<https://ccswitch.io>(唯一官方站点)
- **当前最新版本**:v3.20.1(MIT 开源协议)

## 安装步骤

### 如何下载
推荐官方网站选择自己电脑平台的安装包直接下载
[下载 CC Switch](https://ccswitch.io/zh/download)

## 安装后快速上手

1. **首次启动**:应用会自动检测本机已有的 CLI 工具配置,可手动导入现有配置作为默认 Provider。
2. **添加供应商**:点击右上角"+"→ 选择预设(如 DeepSeek、GLM、MiniMax、Kimi For Coding 等 50+ 预设,多数只需填 API Key)或自定义配置。
3. **切换供应商**:
   - 主界面:选中 Provider → 点击 "Enable"
   - 系统托盘:直接点击供应商名称(即时生效)
4. **生效方式**:切换后重启终端或对应 CLI 工具即生效(**Claude Code 例外,支持热切换,无需重启**)。
5. **切回官方登录**:添加 "Official Login" 预设 → 重启 CLI → 走官方登录/OAuth 流程。

## 常见问题

**Q:切换供应商后没生效?**
A:大部分 CLI 工具需要重启终端;只有 Claude Code 支持无需重启的热切换。

**Q:我的数据存在哪里?**
- 数据库:`~/.cc-switch/cc-switch.db`(SQLite,含供应商、MCP、Prompts、Skills)
- 本地设置:`~/.cc-switch/settings.json`
- 自动备份:`~/.cc-switch/backups/`(保留最近 10 份)

**Q:为什么当前正在使用的供应商不能删除?**
A:CC Switch 遵循"最小侵入"原则,始终保留一份激活配置,避免对应 CLI 工具不可用;不常用的工具可在设置中隐藏。
