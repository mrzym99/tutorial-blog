[PI Agent](https://pi.dev/) 是一款通过命令行使用的 AI 智能体工具，官方通过 npm 分发。本教程以 **npm 安装**为主线，覆盖环境准备、全局安装、首次运行配置、升级卸载以及常见问题排查，帮你几分钟内把 PI Agent 跑起来。

## 一、准备工作

在安装 PI Agent 之前，请确认你的电脑已具备以下条件：

- **Node.js 21 或更高版本**（建议使用 LTS 长期支持版）
- **npm 包管理器**（安装 Node.js 时会自动附带）

打开终端，运行下面两条命令检查环境是否就绪：

```bash
node -v
npm -v
```

如果两条命令都能正常输出版本号（例如 `v22.11.0`、`10.2.4`），说明环境已经准备好了；如果提示 `command not found`，请先安装 Node.js，参考 **VibeCoding** 合集里面的 Node 安装教程。

## 二、用 npm 安装 PI Agent

这是本教程的核心步骤。打开终端，执行以下命令进行**全局安装**（全局安装后可在任意目录直接使用命令）：

```bash
npm i -g @earendil-works/pi-coding-agent 
```

命令说明：

- `npm install`：npm 的安装命令，可简写为 `npm i`
- `-g`：全局安装，命令会注册到系统 PATH 中

### 方式二：国内网络加速（可选）

国内用户如果下载缓慢或超时，可以切换到淘宝镜像源后再安装：

```bash
npm config set registry https://registry.npmmirror.com
```

## 三、验证安装

安装完成后，运行以下命令确认 PI Agent 已正确注册：

```bash
pi --version
```

终端输出版本号（例如 `1.x.0`）就说明安装成功了。如果提示 `command not found`，就重新安装一下。

## 四、使用

（需要先配置模型，可以使用 [cc-swtich](https://ccswitch.io/)/[magpie](https://usemagpie.ai/) 配置）

```bash
pi
```

## 五、升级与卸载

### 升级到最新版

```bash
pi --update
```

### 卸载

```bash
npm uninstall -g @earendil-works/pi-coding-agent 
```

> 如果在安装中遇到问题，建议查阅 PI Agent 官方文档或在社区 / GitHub Issues 中反馈。或者是问你的 AI 聊天助手
