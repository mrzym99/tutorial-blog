# Claude Code 安装教程

> Claude Code 是 Anthropic 出品的 AI 编程命令行工具，可以直接在终端里对话式地读代码、写代码、跑命令、改 bug。
> 整理时间：2026-09 | 资料来源：Anthropic 官方文档

---

## 一、系统要求

| 项目 | 要求 |
|---|---|
| 操作系统 | macOS 13.0+ / Windows 10 1809+ / Ubuntu 20.04+ / Debian 10+ / Alpine 3.19+ |
| 硬件 | 4GB+ 内存，x64 或 ARM64 处理器 |
| 网络 | 需要联网 |
| 终端 | Bash / Zsh / PowerShell / CMD |

**账号要求**：Claude Code 需要 **Claude 付费订阅**（Pro / Max / Team / Enterprise）或 **Anthropic Console** API 额度，也可通过 Amazon Bedrock、Google Vertex AI、Microsoft Foundry 等第三方接入。免费版 Claude 不支持。

---

## 二、安装方式

### 方式一：官方原生安装（推荐）

原生安装**不依赖 Node.js**，且会自动在后台更新到最新版。

**macOS / Linux / WSL：**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**Windows（PowerShell）：**
```powershell
irm https://claude.ai/install.ps1 | iex
```

**Windows（CMD）：**
```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

> Windows 用户建议先安装 **Git for Windows**，这样 Claude Code 内部会优先用 Git Bash 执行命令，体验更好。

### 方式二：Homebrew（macOS）

```bash
brew install --cask claude-code        # stable 稳定版（约滞后一周）
# 或
brew install --cask claude-code@latest # 最新版
```

> 注意：Homebrew 安装**不会自动更新**，升级需执行 `brew upgrade claude-code`。

### 方式三：WinGet（Windows）

```powershell
winget install Anthropic.ClaudeCode
```

> WinGet 安装同样不自动更新，需定期执行 `winget upgrade Anthropic.ClaudeCode`。

### 方式四：npm（需要 Node.js 18+）

```bash
npm install -g @anthropic-ai/claude-code
```

- 该方式装的是与原生安装相同的二进制，安装后 `claude` 命令本身不再依赖 Node。
- **不要使用 `sudo npm install -g`**，容易引发权限问题。
- 升级用：`npm install -g @anthropic-ai/claude-code@latest`（避免 `npm update -g`）。

---

## 三、验证安装

```bash
claude --version   # 输出版本号，如 2.1.x
claude doctor      # 详细检查安装与配置
```

若提示 `command not found`，先重开终端或重新登录，让 PATH 生效。

---

## 四、登录认证

首次使用需要登录你的 Claude 账号：

```bash
cd /你的项目目录
claude
```

终端会提示在浏览器中打开认证链接，按提示完成登录即可。之后也可以在会话中输入 `/login` 重新登录。

**支持的账号类型：**

| 类型 | 说明 |
|---|---|
| Claude 订阅 | Pro / Max / Team / Enterprise |
| Anthropic Console | 开发者 API 额度（console.anthropic.com） |
| 第三方接入 | Amazon Bedrock / Google Vertex AI / Microsoft Foundry |

---

## 五、更新 Claude Code

| 安装方式 | 更新方式 |
|---|---|
| 官方原生安装 | **自动更新**（后台静默完成） |
| Homebrew | `brew upgrade claude-code` |
| WinGet | `winget upgrade Anthropic.ClaudeCode` |
| npm | `npm install -g @anthropic-ai/claude-code@latest` |
| 任意方式 | 想立刻更新：`claude update` |

想控制自动更新渠道（latest / stable）或关闭自动更新，可在 `settings.json` 中配置 `autoUpdatesChannel` 或环境变量 `DISABLE_AUTOUPDATER=1`。

---

## 六、常见问题排查

| 现象 | 解决 |
|---|---|
| `command not found` | 重开终端；确认安装目录已加入 PATH |
| 登录页面打不开 | 确认网络可访问 Anthropic 服务，重新执行 `claude` 获取新链接 |
| Windows 命令执行异常 | 安装 Git for Windows，用 Git Bash 启动 `claude` |
| npm 安装后没有 claude 命令 | 检查是否用了 sudo 安装，或删除后重装：`npm uninstall -g @anthropic-ai/claude-code` |
| 提示无权限访问 | 确认账号为 Pro/Max 等付费订阅，免费版不支持 |

---

## 七、注意事项

- Claude Code 是 **Anthropic 官方服务**，需要付费订阅或 API 额度才能使用，且该服务对所在地区有访问限制，国内网络环境可能无法直接访问，请确认你的账号与网络满足条件后再安装。
- 不想用终端的同学，也可以下载官方 **Claude Desktop 桌面应用**（macOS / Windows），在图形界面里使用 Claude Code 能力。

---

## 八、快速上手

```bash
# 安装（macOS/Linux）
curl -fsSL https://claude.ai/install.sh | bash

# 验证
claude --version

# 进入项目并启动
cd ~/my-project
claude
```

启动后在输入框里用自然语言描述需求即可，比如「帮我把这个页面的报错修一下」「给这个函数写单元测试」。
